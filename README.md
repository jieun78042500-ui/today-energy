# 오늘의 기운

생년월일을 정규화하고 사주 원국을 계산한 뒤, 규칙 기반 생활 해석과 오늘의 실천을 연결하는 한국어 사이트입니다. 9개 화면, 기기 내 기록, 명언 저장, 5분 운동 타이머를 제공합니다.

## 실행

Node.js 22 이상을 사용합니다.

```sh
npm ci
npm run dev       # 화면 개발: http://127.0.0.1:3017
npm test         # 계산·경계·API 단위 테스트
npm run typecheck
npm run build    # Next 정적 화면 + Cloudflare Worker API
node scripts/preview.mjs  # 빌드 결과와 API 함께: http://127.0.0.1:3018
```

화면은 기존 Next.js App Router 구조를 유지합니다. 정적 export는 POST API를 실행할 수 없으므로 동일한 순수 계산 모듈을 호출하는 Worker를 별도로 번들링합니다. `next dev`는 화면 개발용이며 POST API 검증에는 빌드 후 preview를 사용합니다. 배포물은 `dist/server/index.js`, `dist/client`, `dist/.openai/hosting.json`입니다. Worker 기본 export의 fetch는 `/api/*`를 처리하고 나머지를 `env.ASSETS`에 전달합니다. 인증/공유 범위는 기존 Sites 설정을 유지합니다.

## 계산과 해석의 책임

1. `normalizeBirth`: 타입·날짜·시간·미래 입력 검사, 양력 정규화
2. `lunarConversion`: 한국 음력 및 윤달 변환
3. `calculatePillars`: 절기 시각과 일자·시각으로 원국 계산
4. `calculateFiveElements` / `calculateYinYang`: 확정된 글자의 분포
5. `buildSajuProfile`: JSON과 불확실성 경고
6. `interpret`: 10천간 자료와 복수 조건의 생활형 문장
7. `calculateTodayPillar` / `daily`: 실제 날짜 간지, 가중 점수와 행동 안내

런타임 LLM 호출은 없습니다. AI가 년·월·일·시주를 생성하거나 수정하지 않습니다. 자연어도 현재는 자체 템플릿으로 생성합니다. 미래에 LLM을 도입하더라도 계산된 JSON을 설명하는 역할로만 제한해야 합니다. 명리 해석과 점수는 과학적으로 검증된 성격·미래·질병·수익 예측이 아닙니다.

## 사주 계산 기준

- **범위:** 출생일 1900년 이후, 양력 정규화 결과가 현재 시점 이전. 달력 라이브러리 공통 범위를 고려해 2050년까지만 지원합니다. 오늘 조회도 1900~2050년 범위입니다.
- **한국 음력:** `korean-lunar-calendar 0.4.0` 사용. 양력과 음력을 명시적으로 구분하며 윤달 체크를 별도로 받습니다. 없는 윤달과 잘못된 날짜는 거부합니다. 중국 음력으로 한국 음력을 대체하지 않습니다.
- **절기:** `lunar-typescript 1.8.6`의 정확한 절입 기반 `getYearInGanZhiExact`, `getMonthInGanZhiExact`를 사용합니다. 년주는 입춘, 월주는 각 절입 시각에 변경됩니다. 월 숫자로 월주를 구하지 않습니다. 라이브러리 천문 계산의 고정 UTC+08 시간 프레임에 출생 순간을 변환하여 비교합니다.
- **시간대:** 기본 `Asia/Seoul`. Temporal polyfill과 실행 환경의 IANA 시간대 자료를 사용하여 역사적 UTC 오프셋과 서머타임을 처리합니다. 중복/누락되는 출생시각은 자동 추측하지 않고 오류를 표시합니다. 사용자는 확인된 UTC 오프셋(예: `+09:00`)을 입력할 수 있습니다.
- **일주:** 출생지의 민간력 날짜로 계산합니다. 사용자가 선택한 자시 기준만 적용합니다. 위치·경도 기반 진태양시, 균시차, 일괄 30분 보정은 적용하지 않습니다.
- **자시:** 기본 `midnight`는 00:00에 날짜를 바꾸고 23:00~23:59는 당일 일간으로 시주 천간을 구합니다. 선택 가능한 `zi23`는 23:00에 일주를 다음날로 바꾸고 그 일간으로 시주를 구합니다. 두 기준의 결과가 다를 수 있습니다. 시지의 子는 23:00~00:59이며 이후 두 시간 단위입니다.
- **시간 미상:** 시주는 null입니다. 해당 민간 날짜의 시작·끝에서 년주/월주가 다르면 그 기둥도 null로 반환하고 경고합니다. `zi23` + 시간 미상은 일주와 일간도 null입니다. UI에서 임의의 정오 결과를 확정값으로 표시하지 않습니다. 이런 경우 해석의 범위가 제한됩니다.
- **오행:** 확정된 천간 1개와 지지의 대표 오행 1개를 각각 같은 가중치로 셉니다. 미확정 기둥 제외. 정수 비율은 최대 잔여 방식으로 합계 100을 유지합니다. 지장간·통근·득령·계절 가중치·신강약·용신은 미포함입니다. 높은 비중을 실제 명리적 세력으로 부르지 않습니다. 동률은 모두 표시합니다.
- **음양:** 확정된 글자의 음양을 동일 가중치로 합산합니다. 오행과 음양 모두 확정 글자가 전혀 없으면 0입니다.
- **오늘 간지:** 조회 날짜의 민간력 일주이며 조회일은 자정 기준입니다. 기본 오늘 날짜의 갱신 시점은 한국 자정입니다. 출생지 시간대 변경이 앱의 한국 날짜 기준을 변경하지는 않습니다.

절기 초 단위 근사, 시간대 데이터 버전과 학파별 관례에 따라 다른 서비스와 결과가 다를 수 있습니다. 모든 역사적 날짜를 외부 만세력과 전수 대조한 인증 엔진은 아닙니다. 출생시각이 절입 직전에 있다면 입력의 분 단위 정밀도와 라이브러리의 근사 오차를 함께 고려해야 합니다.

## 생활 해석과 점수

10천간의 기본 비유·키워드에 높은/낮은 오행 비중, 일간과 높은 비중의 일치 여부, 음양 분포를 함께 사용합니다. 강점 3개, 주의 3개, 관계·가족·일·소비·스트레스·회복·리듬을 생성합니다. 실제 성격을 단정하지 않습니다.

오늘 점수는 70에서 시작합니다. 오행 상생 관계 +5, 같은 기운 +3 또는 오늘 기운의 극 관계 -5, 낮은 비중 보완 +3, 38% 이상 기운 반복 -3, 반대 음양 보완 +2를 사용합니다. 다섯 분야별 가중치는 `lib/saju/daily.ts`의 `weights`에 공개되어 있으며 반환 JSON에 contributions와 함께 포함합니다. 최종 점수는 반올림 후 45~95로 제한합니다. 전체 점수는 다섯 분야 평균입니다. 무작위 요소는 없습니다. 같은 결과가 다른 날짜에도 반복될 수 있습니다.

가이드·실천·자체 명언·추천 이유·운동은 위 관계와 균형/성장/차분함 키워드에 연결합니다. 건강 항목은 생활 참고 지수로 실제 컨디션을 판단하지 않습니다. 생일 미입력 시 개인 사주인 것처럼 표시하지 않고 일반 가이드를 제공합니다.

## API

모든 엔드포인트는 POST JSON, 응답은 `Cache-Control: no-store`입니다. 서버에 생년월일을 저장하지 않습니다. 브라우저 UI는 개인정보 전송 없이 동일한 계산 모듈을 직접 실행합니다.

```json
POST /api/saju/calculate
{
  "birthDate":"1990-05-15",
  "birthTime":"09:30",
  "calendarType":"solar",
  "timeUnknown":false,
  "leapMonth":false,
  "timezone":"Asia/Seoul",
  "dayBoundary":"midnight"
}
```

응답: `engineVersion`, `birth`, `pillars`, `dayMaster`, `fiveElements`, `yinYang`, `elementInsight`, `warnings`. 미확정 year/month/day/hour는 null일 수 있으므로 호출자가 처리해야 합니다.

`POST /api/saju/interpret`: `{ "sajuProfile": <계산 응답> }`

`POST /api/daily`: `{ "sajuProfile": <계산 응답>, "date":"2026-09-15" }`

interpret/daily는 프로필의 `birth.original`로 원국을 다시 검증·계산하여 요청자가 임의로 바꾼 일간/점수를 신뢰하지 않습니다. 오류는 400, 경로 없음 404, 메서드 오류 405, 큰 요청 413, 콘텐츠 타입 오류 415입니다. 일일 응답에는 요구한 interaction, guide, practice, quote, exercise 및 점수 계산 내역이 포함됩니다.

## 저장과 갱신

- 기기 내 localStorage: userProfile, dailyViews, practiceRecords, exerciseRecords, savedQuotes
- 계산 캐시: `sajuProfile`, `dailyData_YYYY-MM-DD`
- 캐시는 엔진 버전·전체 입력(분·시간대·윤달·자시 포함)·날짜·내용 체크섬이 맞을 때만 사용합니다. 손상/구버전 캐시는 재계산합니다. 체크섬은 우발적 손상 검사용이며 인증 수단이 아닙니다.
- 같은 실행 내에서는 메모리 캐시로 계산 중복을 막습니다. 자정은 60초 간격과 화면 복귀 시 검사합니다. 생일 변경은 오늘 가이드를 갱신하고 과거 기록은 보존합니다. 기존 v2 예시 기록도 당시 값으로 유지합니다.
- 마이페이지에서 JSON 내보내기와 명시적 삭제 확인을 제공합니다. 삭제에는 계산 캐시도 포함됩니다. 기기간 동기화는 없습니다.
